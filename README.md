# Dynamic Markov Blanket Detection

DMBD is a Python and PyTorch framework for estimating statistical
neighborhoods and exploring partitions in numerical data. Its repository
includes a synthetic network fixture and a moving-Gaussian gridworld demo.

- [Documentation](docs/README.md) covers installation, input preparation,
  and verification.
- [Gridworld guide](docs/GRIDWORLD.md) explains the simulator and report outputs.
- [Technical manuscript](docs/manuscript/README.md) compares the detector with
  known synthetic fixture labels and records the limits observed.
- [Archived analysis outputs](DMBD/output/) remain available with the source.

The project was built independently and inspired by
[pyDMBD](https://github.com/bayesianempirimancer/pyDMBD) and
[Beck and Ramstead’s Dynamic Markov Blanket Detection for Macroscopic Physics Discovery](https://arxiv.org/abs/2502.21217).
